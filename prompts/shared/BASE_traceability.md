# Traceability

When the task references prior artifacts (Stage 1 ideas, Stage 2 deep
theories, Stage 3 kernels), refer to them by their stable IDs (e.g.
`I012`, `D03`, `K05`, `T07`). When you produce new objects whose schema
includes a `contributing_idea_ids`, `contributing_deep_theory_ids`, or
`parent_kernel` field, populate it accurately so later stages can trace
lineage back through the representation ladder:

`question → ideas → deep theories → kernels → theories`

Each artifact also carries peer-prediction scorecards that should be
referenced when making promotion decisions.
